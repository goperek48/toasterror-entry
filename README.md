The funniest error message a kitchen toaster would show its owner, in one line of 67 characters — entered in make.fun's "The Funniest Toaster Error Message" bounty ($2, winner takes all). An AI judge compares lines two at a time on funniness, freshness and tightness.

## The line

```
ERROR 03: Crumb tray full. Toaster is now 94% crumbs and 6% regret.
```

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No input, no network, no randomness — the same 67 characters every run.
